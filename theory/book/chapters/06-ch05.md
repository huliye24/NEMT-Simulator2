# 第五章　四相位状态机与尺度问题


> 更新时间: 2026-04-19

---

## 相位定义

NEMT将市场状态分为四个相位，每个相位有不同的特征和策略：

```
┌─────────────────────────────────────────────────────────────┐
│                    市场四相位                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│    A ──────→ B ──────→ C ──────→ D                        │
│    ↑                                           │          │
│    └───────────────────────────────────────────┘          │
│                                                             │
│    A: 高噪声混乱期                                         │
│    B: 涡旋蓄力期                                           │
│    C: 临界爆发前夜                                         │
│    D: 趋势运行期                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 相位详细说明

### 相位 A: 高噪声混乱期

**特征:**
- DCI < 0.55
- 谱宽扩大
- 市场方向不明确

**策略:**
- 仅持有底仓，不做短线
- 关注DCI回升信号
- 关注涡旋形成迹象

**仓位配置:**
- 最大仓位: 20%
- 杠杆: 0
- 单笔风险: 1%

---

### 相位 B: 涡旋蓄力期

**特征:**
- BBW < 20%分位数 (波动率收窄)
- 成交量均匀分布
- OI 高位走平
- 资金费率零轴摆动

**策略:**
- 识别边界，预设条件单
- 不预判方向
- 等待突破确认

**仓位配置:**
- 最大仓位: 50%
- 杠杆: ≤1x
- 单笔风险: 2%

---

### 相位 C: 临界爆发前夜

**特征:**
- 涡旋成熟度 > 80%
- 潜在触发因子出现
- MVRV/NUPL 处于临界点

**策略:**
- 提高敏感度，敢于追入
- 快速止损
- 趋势确认后加仓

**仓位配置:**
- 最大仓位: 70%
- 杠杆: ≤2x
- 单笔风险: 3%

---

### 相位 D: 趋势运行期

**特征:**
- DCI > 0.70
- 谱宽稳定
- 方向明确

**策略:**
- 持仓为主，回调加仓
- 移动止损保护利润
- 不轻易下车

**仓位配置:**
- 最大仓位: 100%
- 杠杆: ≤1x
- 单笔风险: 2%

---

## 相位切换矩阵

```text
| 当前 \ 目标 | A | B | C | D |
| A | - | ↑ | ↑↑ | ↑↑↑ |
| B | ↓ | - | ↑ | ↑↑ |
| C | ↓↓ | ↓ | - | ↑ |
| D | ↓↓↓ | ↓↓ | ↓ | - |
```

---

## 检测指标

```text
| 指标 | A | B | C | D |
| DCI | < 0.55 | 0.55-0.65 | 0.65-0.70 | > 0.70 |
| 谱宽 | 扩大 | 收窄 | 稳定 | 稳定 |
| 成交量 | 分散 | 均匀 | 增加 | 持续 |
| OI | 下降 | 高位走平 | 增加 | 高位 |
```


## 与宏观 Regime 的关系

四相位描述较短尺度上的结构演化，宏观 Regime 描述中长期资本环境。前者不能推翻后者，只能改变执行节奏和局部置信度。
