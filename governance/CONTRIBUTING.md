# 研究贡献指南

本仓库是纯研究与纯策略规范仓库。

允许：Markdown / 公式 / 无可执行性的示意图、带来源的实验设计与研究报告、策略自然语言说明、参考文献及其审查记录。

禁止：后端、前端、桌面软件、自动下单模块、交易密钥、运行环境、依赖文件、编译产物、数据库、可执行交易策略代码和未授权的数据集。

每次修改应注明：研究编号、假设版本、来源、变更原因、预先设定的反证条件，以及哪些历史结论随之失效。

提交前核对：
- [ ] 不包含可运行代码或凭据；
- [ ] 实验结果有证据出处，不把历史计划标为已完成；
- [ ] 假设与结论明确分开；
- [ ] 负结果和局限性保留；
- [ ] 研究引用可追溯；
- [ ] 不擅自变更已有著作权/许可证说明。
