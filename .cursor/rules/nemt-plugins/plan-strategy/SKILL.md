  ### Step 2: 技术架构设计

  #### 2.1 策略模块架构

  ```
  src/strategies/[strategy-name]/
  │
  ├── index.ts              # 策略主入口
  │
  ├── signals/              # 信号生成层
  │   ├── nemt.ts         # NEMT 状态机接口
  │   ├── entry.ts        # 入场信号生成
  │   ├── exit.ts         # 出场信号生成
  │   └── composite.ts     # 信号组合
  │
  ├── indicators/           # 技术指标层
  │   ├── momentum.ts     # 动量指标 (RSI, MACD)
  │   ├── trend.ts        # 趋势指标 (MA, ADX)
  │   └── volatility.ts    # 波动率指标 (ATR, BB)
  │
  ├── risk/                # 风险管理层
  │   ├── position.ts      # 仓位计算
  │   ├── stoploss.ts     # 止损逻辑
  │   ├── takeprofit.ts   # 止盈逻辑
  │   ├── drawdown.ts     # 回撤控制
  │   └── exposure.ts      # 风险敞口
  │
  ├── backtest/            # 回测模块
  │   ├── engine.ts       # 回测引擎
  │   ├── executor.ts     # 订单执行模拟
  │   └── analytics.ts    # 绩效分析
  │
  └── tests/               # 测试
      ├── signals.test.ts
      ├── risk.test.ts
      └── integration.test.ts
  ```

  #### 2.2 数据流设计

  ```
  Binance API
      ↓
  KLine 数据流
      ↓

  │ NEMT State     │  ← ψ, φ, 熵, 相位

  └────────┬────────┘
           │
      ┌────┴────┐
      ↓         ↓
  ┌────────┐ ┌──────────┐
  │ Signals │ │Indicators│
  │ Module  │ │ Module   │
  └────┬────┘ └────┬─────┘
       │            │
       └─────┬──────┘
             ↓
        Signal +
        Indicators
             ↓
  ┌─────────────────┐
  │ Risk Manager    │  ← 仓位, 止损, 风控
  └────────┬────────┘
           │
      ┌────┴────┐
      ↓         ↓
  ┌────────┐ ┌────────┐
  │ Backtest│ │ Live   │
  │ Engine │ │ Trade  │
  └────────┘ └────────┘
  ```
