# NEMT 核心概念

## NEMT 状态机

NEMT (Non-Equilibrium Market Theory) 是 NEMT Simulator 的核心算法，基于市场非平衡态理论。

### 三个核心指标

| 指标 | 符号 | 定义 | 计算方式 |
|------|------|------|----------|
| **增长率 (Psi)** | ψ | 市场平均收益率的指数加权动量 | EMA(returns, α=0.3) × 100 |
| **衰减率 (Phi)** | φ | 市场波动性的年化值 | σ(returns) × √252 × 100 |
| **熵 (Entropy)** | S | 市场状态的不确定性 | H(price_histogram) / H_max |

### 五个市场相位

| 相位 | 条件 | 含义 | 交易信号 |
|------|-------|------|----------|
| **stable** | ψ 适中 且 S 低 | 市场稳定，趋势不明显 | HOLD |
| **critical_up** | ψ 高 且 S 高 | 临界上涨，强势突破 | BUY |
| **critical_down** | ψ 低 且 S 高 | 临界下跌，强势下跌 | SELL |
| **critical** | S 高 | 市场临界状态，方向不明 | 观望 |
| **decay** | ψ 适中 且 S 低 | 市场衰减期 | 轻仓 |

### NEMT 决策逻辑

```
IF entropy > CRITICAL_ENTROPY (0.7):
    IF psi > CRITICAL_PSI (0.7):
        SIGNAL = BUY      // 临界上涨
    ELSE IF psi < -CRITICAL_PSI (-0.7):
        SIGNAL = SELL     // 临界下跌
    ELSE:
        SIGNAL = HOLD     // 方向不明
ELSE IF entropy < LOW_ENTROPY (0.3):
    IF psi > STABLE_PSI (0.5):
        SIGNAL = BUY      // 稳定趋势
    ELSE IF psi < -STABLE_PSI (-0.5):
        SIGNAL = SELL     // 稳定下跌
    ELSE:
        SIGNAL = HOLD     // 稳定无趋势
ELSE:
    SIGNAL = HOLD         // 中等熵，观望
```


## 回测指标定义

### 核心指标

| 指标 | 公式 | 含义 |
|------|------|------|
| **总收益率** | (最终资金 - 初始资金) / 初始资金 × 100% | 策略总体收益 |
| **年化收益率** | (最终资金/初始资金)^(252/交易天数) - 1 × 100% | 年化收益 |
| **夏普比率** | E(Rp-Rf) / σp × √252 | 风险调整收益 |
| **索提诺比率** | E(Rp-Rf) / σ_down × √252 | 下行风险调整收益 |
| **最大回撤** | max(Peak - Trough) / Peak × 100% | 最大亏损幅度 |
| **卡玛比率** | 年化收益 / 最大回撤 | 收益/风险比 |

### 交易指标

| 指标 | 公式 | 含义 |
|------|------|------|
| **胜率** | 盈利交易数 / 总交易数 × 100% | 盈利概率 |
| **盈亏比** | 平均盈利 / 平均亏损 | 盈亏平衡点 |
| **盈利因子** | 总盈利 / 总亏损 | 总体盈利倍数 |
| **平均交易次数** | 总交易数 / 交易天数 | 交易频率 |

### NEMT 特有指标

| 指标 | 定义 | 含义 |
|------|------|------|
| **ψ 准确率** | ψ方向正确时的交易胜率 | NEMT 信号准确性 |
| **相位胜率** | 各相位的平均胜率 | 相位有效性 |
| **临界胜率** | critical_up/down 时的胜率 | 核心信号质量 |

## 风险模型

### 仓位计算 (Kelly Criterion 简化版)

```
f* = (p × b - q) / b

其中:
- p = 胜率
- q = 1 - p
- b = 盈亏比

建议仓位 = f* × 资金 × 0.5 (半 Kelly)
```

### VaR (Value at Risk)

```
日 VaR(95%) = 资金 × σ_daily × 1.65
周 VaR(95%) = 资金 × σ_daily × √7 × 1.65
```
