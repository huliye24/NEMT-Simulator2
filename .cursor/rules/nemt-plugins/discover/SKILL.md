  # /discover -- 策略发现

  运行一个结构化的策略发现流程，从数据分析、市场研究到假设识别，找到有潜力的交易策略方向。

  ## 触发条件

  当用户提供以下类型的输入时触发此命令：
  - 发现新的交易策略方向
  - 分析市场数据寻找机会
  - 研究交易假设
  - 探索新的技术指标组合

  ## 工作流

  ### Step 1: 理解发现上下文

  确定发现的目标：
  - **市场选择**: 现货 / 合约 / 期权
  - **资产类别**: 加密货币 / 股票 / 外汇
  - **时间周期**: Scalping / Day / Swing / Position
  - **策略类型**: 趋势 / 突破 / 均值回归 / 套利

  询问用户：
  - 你想发现什么类型的策略？（趋势跟踪、突破策略等）
  - 你有哪些市场数据或研究？（如果有）
  - 这个发现是为了什么决策？（新策略 / 优化现有策略 / 风险对冲）

  ### Step 2: 市场分析 (发散阶段)

  应用市场分析技能，从多个角度发现机会：

  #### 2.1 技术分析视角
  - 识别价格形态（头肩顶/底、三角形、旗形）
  - 分析技术指标（MA, RSI, MACD, Bollinger Bands）
  - 寻找支撑阻力位
  - 识别波动率变化

  #### 2.2 市场结构视角
  - 识别市场周期（积累/分配/抬高/派发）
  - 分析订单簿结构
  - 寻找流动性池
  - 识别聪明钱流向

  #### 2.3 NEMT 视角
  - 分析当前 NEMT 相位分布
  - 识别相位转换模式
  - 计算 ψ/φ/熵 的历史分布
  - 寻找有效相位组合

  #### 2.4 统计视角
  - 均值回归特性
  - 动量持续性
  - 相关性分析
  - 季节性模式

  ### Step 3: 假设识别 (关键思考阶段)

  对于每个发现的机会，识别核心假设：

  #### 3.1 价值假设 (Value)
  - 这个策略能盈利吗？
  - 市场是否足够有效以提供这种机会？
  - 预期收益是多少？

  #### 3.2 可行性假设 (Feasibility)
  - 我们能准确识别入场点吗？
  - 执行延迟是否影响策略？
  - 数据质量是否足够？

  #### 3.3 风险假设 (Risk)
  - 最大亏损是多少？
  - 策略在极端市场条件下表现如何？
  - 回撤持续时间是多久？

  #### 3.4 NEMT 假设
  - NEMT 相位与策略信号的相关性
  - ψ/φ 的预测能力
  - 熵值作为趋势确认指标

  ### Step 4: 优先级排序 (聚焦阶段)

  应用优先级框架对假设排序：

  #### Impact × Uncertainty 矩阵

  ```
  高影响, 高不确定性 = 最优先验证 ← "信仰一跃"假设
  高影响, 低不确定性 = 快速实施
  低影响, 高不确定性 = 低优先级
  低影响, 低不确定性 = 忽略
  ```

  #### 策略发现评分卡

  | 维度 | 评分 (1-5) | 权重 |
  |------|------------|------|
  | 预期收益 | | 25% |
  | 风险可控性 | | 25% |
  | 技术可行性 | | 20% |
  | 市场适用性 | | 15% |
  | NEMT 整合度 | | 15% |

  ### Step 5: 策略构思 (验证阶段)

  对于高优先级假设，设计初步策略：

  #### 策略卡片格式

  ```
  ## 策略卡片 #[N]

  **策略名称**: [描述性名称]
  **策略类型**: [趋势/突破/均值回归/套利]
  **核心假设**: [高优先级假设]

  **入场条件**:
  1. [条件1]
  2. [条件2]

  **出场条件**:
  1. [条件1]
  2. [条件2]

  **风险参数**:
  - 止损: [%]
  - 止盈: [%]
  - 仓位: [%]

  **预期表现**:
  - 胜率: [%]
  - 盈亏比: [:1]
  - 夏普比率: [预计]

  **NEMT 整合**:
  - 相关相位: [列表]
  - ψ 阈值: [值]
  - 熵 阈值: [值]

  **假设验证计划**:
  - [假设1] → [验证方法]
  - [假设2] → [验证方法]
  ```

  ### Step 6: 创建发现计划

  整理所有发现，生成发现计划文档：

  ```markdown
  ## 策略发现计划: [主题]

  **日期**: [今天]
  **发现范围**: [市场/资产/周期]
  **发现方法**: [数据分析/研究/直觉]

  ### 市场分析摘要
  [关键发现]

  ### 识别的策略机会
  || # | 策略 | 核心假设 | 影响 | 不确定性 | 优先级 |
  ||---|-----|--------|------|---------|--------|
  || 1 | | | 高/中/低 | 高/中/低 | P1/P2/P3 |

  ### 策略卡片
  [策略1详情]
  [策略2详情]

  ### 下一步
  - [ ] 使用 /write-strategy 创建策略1规范
  - [ ] 使用 /write-strategy 创建策略2规范
  - [ ] 使用 /discover 深入分析策略1
  ```

  ### Step 7: 建议下一步

  发现完成后，主动提供：
  - "是否需要深入分析某个策略？"
  - "是否创建策略规范？使用 /write-strategy [策略名称]"
  - "是否运行初步回测？使用 /backtest [策略ID]"

  ## 规则

  - 每个发现阶段都要有具体的分析或数据支持
  - 假设必须明确声明，不确定的地方要标注
  - 策略卡片要足够具体，可以直接用于编写策略规范
  - NEMT 视角始终贯穿整个发现过程
  - 如果用户有现成的市场数据，优先分析数据而非凭空假设
