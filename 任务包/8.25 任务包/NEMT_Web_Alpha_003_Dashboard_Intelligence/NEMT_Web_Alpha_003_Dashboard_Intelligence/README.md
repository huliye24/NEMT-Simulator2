# NEMT Web Alpha 003 --- Dashboard Intelligence Layer

## Mission

建立 NEMT 第一个真正可展示的金融智能 Dashboard。

目标：

打开网页后，用户可以立即理解：

NEMT 正在观察市场， 理解市场状态， 生成 AI 金融判断。

## 本阶段核心

Dashboard = NEMT 的驾驶舱。

包括：

-   Market State
-   NEMT Phase
-   DCI Indicator
-   AI Confidence
-   Risk Level
-   AI Market Report

## 不包含

-   真实交易
-   Binance API
-   自动执行

继续使用 Mock Data。
