# NEMT Web Alpha 001 工程任务包

## Mission

将 NEMT-Simulator2 从金融实验系统升级为 AI Financial Intelligence Web
Alpha。

目标：

建立一个可运行的 Web 产品雏形，让用户看到：

Human Judgment + AI Execution

## 本阶段目标

不是自动交易系统。

第一阶段只完成：

-   Web Dashboard
-   市场状态展示
-   AI分析报告展示
-   模拟交易展示
-   交易日志结构
-   后续 API 接口预留

## 核心原则

1.  先运行，再优化。
2.  保留 NEMT Engine 独立性。
3.  前端不绑定真实交易。
4.  使用 Mock 数据完成第一版生命体。
