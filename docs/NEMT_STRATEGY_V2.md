# NEMT Strategy v2 — 持仓状态升级

## 数据结论

2026年6月至8月的随机节点消融实验表明：

- 年度趋势作为硬过滤会因滞后错过反转，予以撤销。
- 连续同向信号有时代表重复风险，有时代表趋势持续，不能简单全部删除。
- 独立节点模型允许持仓重叠，会夸大交易数、收益和回撤，不再作为上线依据。

## v2 规则

1. ψ、熵和临界相位公式保持不变，避免同时修改理论与执行层。
2. 单账户同一时间只允许一个方向仓位。
3. 空仓遇到 `critical_up/down` 开仓；同向临界信号为 `HOLD`，不重复开仓。
4. 反向临界信号执行反转；`decay` 平仓；`critical/stable` 保持当前仓位。
5. 年度趋势只影响风险规模：顺势100%、中性/未知75%、逆势50%，不禁止交易。
6. 在连续账户回测证明安全前，杠杆只使用3×或5×，暂停10×。
7. 止损继续使用1.5×ATR（限制1%–5%），止盈基准2R；执行层必须记录实际原因。

## 升级门槛

胜率只作为诊断指标，不再作为淘汰门槛。必须在连续、非重叠、样本外资金曲线上同时满足：总收益为正、每笔期望值为正且期望比率≥0.05、盈利因子≥1.2、夏普≥1.5、最大回撤≤20%、盈亏比≥1.2，且至少20笔已完成交易，才可进入模拟盘候选。跨区间结果还必须保持同号，避免仅由单一行情贡献全部收益。

## v3 修订（连续回测后）

2026年6月至9月连续回测显示 v2 最大回撤59.76%，年度熊市标签放大了亏损空头并缩小了盈利反转多头。因此 v3：

- 年度趋势仅记录，不再参与交易许可或仓位计算。
- 每笔按止损距离反推仓位，使理论止损风险不超过当时权益2%。
- 反向临界相位必须连续确认2根已完成4小时K线才允许反转。
- 止损后冷却2根4小时K线，防止在同一失败相位立即重新入场。
- 保持单账户、不重叠、3×/5×杠杆上限和2R止盈。
