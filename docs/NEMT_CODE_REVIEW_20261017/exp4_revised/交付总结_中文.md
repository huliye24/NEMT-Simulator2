## 💡 核心设计原则

### R4 协议修正

1. **充分分辨孤子**: L=20, N_min=256 → 15.3 点/FWHM (原版 6.3)
2. **固定物理时间**: 每个部分固定 T (而非固定步数)
3. **单一参考**: 解析孤子 (而非数值 SSFM)
4. **严格统计**: R² ≥ 0.90, 斜率 ∈ [1.65, 2.35]
5. **可重复性**: 所有参数冻结 (α=0.1, β=1.0, A=1)

### 四个子实验

**A. 空间收敛** (T=0.2s, dt=2e-5)
- 网格: N ∈ [256, 384, 512, 768]
- 测量: L2, L∞, 质量守恒

**B. 时间收敛** (N=1024, T=0.5s)
- 求解器: Euler, RK4, Strang
- 时间步: dt ∈ [0.008, 0.004, 0.002, 0.001]
- 提取: 时间阶数 (p ≈ 4 for RK4)

**C. 可靠性边界** (T=0.2s)
- 扫描: μ ∈ [0.005, 6] (25 个对数间隔点)
- 标准: finite && max_ratio≤10 && mass≤1e-3 && L2≤0.05
- 拟合: log(dt_r) ~ log(dx)

**D. 长时演化** (T=5s, μ=0.2)
- 网格: N ∈ [256, 384, 512, 768]
- 验证: 辛结构保持 (质量漂移 < 1e-10)

### 五个统计门控

| 门控 | 标准 | 阈值 | 目的 |
|------|------|------|------|
| R4.1 | 最粗网格 点/FWHM | ≥12 | 充分空间分辨 |
| R4.2 | 空间误差单调性 | True | 收敛确认 |
| R4.3 | RK4 时间阶数 | ∈[3.5,4.5] | 理论匹配 |
| R4.4 | 边界缩放 R² | ≥0.90 | 稳定性缩放律 |
| R4.4 | 边界缩放斜率 | ∈[1.65,2.35] | dt ∝ dx² 确认 |
| R4.5 | 长时 L2 误差 | <2% | 守恒验证 |
| R4.5 | 长时质量漂移 | <1e-10 | 辛性质 |
