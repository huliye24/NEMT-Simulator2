# NEMT Strategy v4 — 浮盈金字塔与保护止损

v4 不修改 NEMT 的 ψ、熵或方向信号，只升级盈利持仓的管理方式。

## 共同约束

- 初始仓仍使用 v3 的2%止损风险预算和3×/5×杠杆。
- 只在已有浮盈且NEMT仍确认同向时加仓，禁止亏损补仓。
- 最多加仓两次，新增名义仓位依次为首仓的50%和25%。
- 加仓触发点为首仓风险距离的 +1R 和 +2R。
- 总名义仓位不得超过当时权益的3倍。
- 保护止损只能向盈利方向移动，绝不能放宽。
- 年度趋势继续仅作研究标签，不参与滚仓许可。

## 对照版本

- v4-A：两次浮盈加仓；首次加仓后把保护止损推进到含成本缓冲的保本区域。
- v4-B：两次浮盈加仓；使用2×ATR跟踪止损，让大趋势继续运行。
- v4-C：不加仓，取消固定2R止盈，仅使用2×ATR跟踪止损，用于隔离“持有更久”的贡献。

“成本下降”在这里指受保护的账户本金风险下降，而不是会计平均入场价下降。做多追涨加仓通常会提高平均买入价，做空追跌加仓通常会降低平均卖出价；安全性来自收紧整体止损和限定新增风险。

## v4.1 自适应滚仓

固定 `+1R/+2R` 与固定50%/25%仅保留为基准。正式候选按每根K线的边际价值动态计算：

`新增名义仓位 = min(剩余风险预算上限, 分数Kelly上限, 保证金上限)`。

- 剩余风险预算 = 权益×2% + 已锁定浮盈 − 当前仓位止损最坏损失。
- 分数Kelly使用条件胜率与盈亏比，并乘以NEMT质量、状态置信度和回撤抑制系数。
- NEMT方向未确认、质量低于0.60、质量较上一根恶化、期望边际非正或回撤达到20%时禁止加仓。
- 手续费、滑点与资金费率以成本缓冲计入新增仓位到止损的风险距离。
- 不预设加仓次数；风险预算、Kelly和总名义仓位上限自然约束规模。小于最小下单额的建议视为不加仓。
- 条件胜率必须来自严格样本外同类状态记录；样本不足时应收缩到保守先验，禁止用主观置信度代替。

## 评价标准修订

胜率不再是硬门槛。趋势策略允许多数小额止损，由少数大趋势贡献主要利润。正式审核使用正期望重复博弈标准：总收益为正、期望比率≥0.05、盈利因子≥1.2、盈亏比≥1.2、夏普≥1.5、最大回撤≤20%、至少20笔交易，并要求多个连续样本区间保持正期望。胜率继续披露，但只用于诊断信号频率和亏损簇，不单独决定通过或失败。

## v4.2 稳健期望对数增长

动态仓位不再直接使用样本胜率和平均盈亏比。v4.2 对胜率使用 Beta 后验的保守下界，对平均盈利和亏损进行先验收缩，并以最差10%亏损的 CVaR 约束尾部风险。随后在仓位网格上最大化保守期望对数增长：

`G(f)=p_low·log(1+f·W_shrunk)+(1-p_low)·log(1-f·L_upper)`。

只有至少20笔已完成同类交易、稳健期望为正、单笔风险≤权益2%、尾部CVaR风险≤权益3%、当前回撤低于20%时才允许新增风险。一次异常巨额盈利会被收缩，不能单独把策略或滚仓判为有效。

## v4.3 趋势可滚动性许可

v4.3将首仓与加仓彻底分离。首仓仍由NEMT临界信号决定；加仓前，以当前NEMT质量、质量变化、熵变化、ATR变化、浮盈R和相位年龄寻找历史相似状态，并计算加权Beta后验。只有相似历史有效样本≥20、趋势持续概率保守下界≥0.45、滚仓边际期望≥0.05R时，才把许可交给v4.2计算仓位。许可失败时保持现有仓位并继续保本或ATR保护，绝不增加风险。
