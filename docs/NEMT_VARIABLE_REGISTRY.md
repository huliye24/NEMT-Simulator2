# NEMT 变量注册表

版本：v0.1　日期：2026-10-17　对应代码：`nemt_os/services/research/variables.py`

## 0. 纪律

1. **每个变量必须有确定、可复现的计算定义。** 禁止用「情绪」「噪声」「临界点」等无法计算的词作为变量定义。
2. **所有变量在 t 时刻的取值只能使用 t 及 t 之前的数据。** 不使用全样本统计量做归一化。
3. **缺失值一律为 `None`**，绝不用 0.5 / 0.02 等「看起来中性」的默认值伪装成信号。
4. **代理量必须显式标注。** 当理论原条件需要 OHLCV 之外的数据（OI、资金费率、链上指标）而不可得时，本注册表用 OHLCV 可计算的替代量，并明确声明这是代理、不是原条件。
5. 任何理论定义的变化都必须同步更新本文件，不得静默修改公式。

## 1. 参数分层（重要）

| 层 | 参数 | 是否参与调参 | 理由 |
|---|---|---|---|
| **理论层** `NEMTConfig` | `alpha`、`beta`、`eta`、`psi_window`、`nls_steps`、`nls_dt` | **不参与调参** | 这些是物理模型参数，若按数据拟合则等于用结果反推前提，构成循环论证 |
| **观测层** | `dci_window`、`bbw_window`、`rvol_window`、分位窗口 | **固定** | 观测窗口，需在实验前冻结 |
| **决策层** | `vortex_trigger`、`resonance_trigger`、事件阈值、策略参数 | **允许在训练集选择** | 这才是可调的决策阈值 |

这一分层使得 NEMT 变量**只需计算一次**，策略参数扫描与 walk-forward 可以复用，既省算力也避免了「每次调参都重算理论变量」带来的隐性前视。

## 2. 变量定义

### 2.1 psi（市场状态复振幅）

| 项 | 内容 |
|---|---|
| 理论含义 | 市场状态的复振幅，NLS 方程的场量。实部表示相对均衡位置的偏离，虚部表示动量（正交象限） |
| 可观测代理 | 对数价格的滚动 z-score（实部）；对数收益率的滚动 z-score（虚部） |
| 输入字段 | `close` |
| 公式 | `psi_re[t] = (log P[t] - mean(log P[t-W+1..t])) / std(log P[t-W+1..t])`<br>`psi_im[t] = (r[t] - mean(r[t-M+1..t])) / std(r[t-M+1..t])`，`r[t] = log(P[t]/P[t-1])` |
| 计算窗口 | `W = psi_window = 128`（实部），`M = momentum_window = 24`（虚部） |
| 输出范围 | 实部/虚部理论无界，实践中约 [-4, 4] |
| 缺失值处理 | 窗口不足 → `None`。标准差为 0 → 返回 `0.0`（此时确为无偏离，不是伪造） |
| 是否使用未来数据 | **否**。仅用 t 及 t 之前的滚动窗口 |
| 理论预测 | 市场接近临界态时，psi 的空间剖面向少数频率集中 |
| 否证条件 | 若 psi 剖面在「临界态」与「非临界态」下的频谱没有可区分的结构差异，则该构造不成立 |

> **与旧实现的差异（重要）**：`nemt_core.py:72` 使用**全样本** mean/std 做归一化，用未来 K 线构造 psi。本实现改为滚动窗口，消除该前视。

### 2.2 alpha（扩散系数 / 市场流动性）

| 项 | 内容 |
|---|---|
| 理论含义 | NLS 的色散强度，对应市场流动性深度：alpha 越大，扰动扩散越快、结构越易被抹平 |
| 可观测代理 | **当前版本无数据驱动的估计方法**，为配置常数 |
| 输入字段 | 无 |
| 公式 | 常数 `alpha = 0.1` |
| 计算窗口 | 不适用 |
| 输出范围 | 配置常数 |
| 缺失值处理 | 不适用 |
| 是否使用未来数据 | 不适用 |
| 理论预测 | 高 alpha 市场中，局部结构更快衰减，谱宽更大 |
| 否证条件 | 若改变 alpha 后谱宽与后续趋势扩张的关系不发生系统性变化，则 alpha 的「流动性」解释不成立 |

> ⚠️ **已知缺口（如实记录）**：NEMT 理论要求从市场估计 alpha。仓库内所有历史实现（含 `nemt_core.py`、`nls_solver.py`、`high_performance_nls.py`）**均为硬编码常数，零处从数据估计**。第一阶段不假装已实现，标记为待办 R3。

### 2.3 beta（非线性系数 / 羊群与杠杆效应）

| 项 | 内容 |
|---|---|
| 理论含义 | NLS 的非线性自聚焦强度，对应情绪、杠杆、羊群效应：beta 越大，偏离越自我强化 |
| 可观测代理 | **当前版本无数据驱动的估计方法**，为配置常数 |
| 公式 | 常数 `beta = 1.0` |
| 是否使用未来数据 | 不适用 |
| 理论预测 | 高 beta 市场中，psi 偏离会自我放大，形成尖峰（涡旋 → 爆发） |
| 否证条件 | 若 beta 的符号与大小对事件后的收益分布无系统影响，则该解释不成立 |

> ⚠️ 同 alpha，标记为待办 R3。

### 2.4 eta（外部噪声）

| 项 | 内容 |
|---|---|
| 理论含义 | 随机扰动 / 外部信息流 |
| 可观测代理 | 高斯白噪声，强度 `eta` |
| 输入字段 | 无（由随机数发生器产生） |
| 公式 | 每步 `psi += N(0, eta·√dt)`，**使用固定种子 `random_seed` 的 `random.Random`** |
| 计算窗口 | 每 NLS 步施加一次 |
| 输出范围 | `eta ≥ 0`，默认 `0.0`（确定性演化） |
| 缺失值处理 | 不适用 |
| 是否使用未来数据 | **否**。噪声是外生注入的，且种子固定，可复现 |
| 理论预测 | 中等强度的噪声能通过随机共振放大弱信号；过强则淹没 |
| 否证条件 | 若事件检测结果随种子显著变化，则 eta 的取值不可用于研究（应先降为 0） |

> 默认 `eta = 0.0`，保证第一阶段结果**完全确定性**。

### 2.5 DCI（方向一致性指数）

| 项 | 内容 |
|---|---|
| 理论含义 | 市场方向一致性的度量：一致上涨或一致下跌的 K 线占比越高，方向越明确 |
| 可观测代理 | 滚动窗口内上涨/下跌 K 线根数的较大者占比 |
| 输入字段 | `open`、`close` |
| 公式 | `U = #{close > open}`，`D = #{close < open}`（窗口内）<br>`DCI = max(U, D) / n_window` |
| 计算窗口 | `dci_window = 24` |
| 输出范围 | 理论 [0, 1]；大量十字星时可低于 0.5，实践中 [0.5, 1.0] |
| 缺失值处理 | 窗口不足 → `None`。**不返回 0.5 伪装中性** |
| 是否使用未来数据 | **否** |
| 理论预测 | DCI 高位 → 趋势；DCI 低位 → 混乱；DCI 由低转升 → 方向正在形成 |
| 否证条件 | 若 DCI 与未来收益的方向一致性无显著关联，则 DCI 不携带方向信息 |

> **与旧实现的差异**：`nemt_signals.py:156` 在 n<2 时返回 `0.5` 伪装成「medium/neutral」信号。本实现返回 `None`。

### 2.6 spectral_width（谱宽）

| 项 | 内容 |
|---|---|
| 理论含义 | psi 空间剖面功率谱的频率离散度。谱宽小 = 能量集中在少数频率 = 结构单一、接近临界；谱宽大 = 能量分散 = 结构混乱 |
| 可观测代理 | psi 剖面经 NLS 演化后的功率谱二阶矩 |
| 输入字段 | `psi_re`、`psi_im`（由 `close` 导出） |
| 公式 | `P_k = \|X_k\|² / N²`（单边功率谱，k = 0..N/2）<br>`w_k = P_k / ΣP_k`<br>`f_k = k / N`<br>`μ = Σ w_k f_k`<br>`spectral_width = sqrt( Σ w_k (f_k - μ)² )` |
| 计算窗口 | `psi_window = 128` 根剖面，`N = psi_n_fft = 128` 点 FFT |
| 演化 | split-step Fourier，`nls_steps = 20` 步，`dt = 0.01` |
| 输出范围 | [0, 0.5]（归一化频率轴上，Nyquist = 0.5） |
| 缺失值处理 | 总功率 ≤ 1e-300 → 返回 `0.0`（常数序列确实无频谱结构，不是伪造） |
| 是否使用未来数据 | **否**。只用 t-W+1..t 的剖面 |
| 理论预测 | 谱宽处于历史低分位 → 市场结构收缩 → 后续易发生方向性扩张 |
| 否证条件 | 若低谱宽时点的未来收益分布与随机时点无异，则该预测被否证 |

> **与旧实现的差异（关键纠错）**：
> - `enhanced_phase_detector.py:353` 与 `nemt_model_node.py:585` 用 `np.std(功率谱数组值)` 冒充谱宽，**完全不含频率轴**，是假指标，本实现已纠正。
> - `nls_solver.py:274/287` 在退化时硬编码返回 `0.02`；`web-vite-backup/.../nemtCore.ts:418` 返回 `0.015 + Math.random()*0.01` **随机数**。本实现返回 `0.0` 且不使用随机数。
> - 仓库内谱宽共 7 份互不兼容的实现（幅度 vs 功率加权、单边 vs 双边、是否归一化）。本实现统一为：**单边 + 功率加权 + 不归一化**。

### 2.7 vortex_score（涡旋成熟度）

| 项 | 内容 |
|---|---|
| 理论含义 | 市场多空力量僵持、能量积聚但方向未定的状态 |
| 可观测代理 | 四个子条件的均值 |
| 输入字段 | `close`（BBW、已实现波动率）、`open`/`close`（涨跌根数）、`dci` |
| 公式 | `v1 = 1 - percentile_rank(BBW, Wv)`<br>`v2 = 1 - percentile_rank(RVOL, Wv)`<br>`v3 = 1 - \|up_ratio - 0.5\|·2`<br>`v4 = 1 - \|DCI - 0.5\|·2`<br>`vortex_score = mean(v1..v4)` |
| 计算窗口 | `bbw_window = 20`，`rvol_window = 24`，分位窗口 `168`，`dci_window = 24` |
| 输出范围 | [0, 1] |
| 缺失值处理 | 全部子项缺失 → `None`；部分缺失 → 对可用项取均值 |
| 是否使用未来数据 | **否**。分位排名只回看过去窗口 |
| 理论预测 | 涡旋期越成熟，后续突破的幅度越大 |
| 否证条件 | 若涡旋评分高低与后续波动扩张无单调关系，则该构造不成立 |

> ⚠️ **代理量声明（必须随报告一起呈现）**：NEMT 原文四条件为
> ① BBW 低分位 ② 成交量涨跌均匀分布 ③ OI 高位走平 ④ 资金费率零轴摆动。
> **③ ④ 需要 OI 与资金费率数据，OHLCV 无法计算。** 本实现替换为
> ③' 已实现波动率低分位、④' DCI 接近 0.5；② 因 OHLCV 无买卖成交量拆分，退化为涨跌**根数**均衡。
> 这是**代理，不是原条件**，结论的适用范围受此限制。

> **与旧实现的差异**：`nemt_signals.py:255` 对整段 `bbw_history` 求分位（全样本前视），同函数 L282 却写了 `oi_values[-30:]`，自相矛盾。本实现统一为回看窗口。旧实现的 maturity **无上界（可达 20）**，本实现裁剪到 [0,1]。

### 2.8 resonance_score（随机共振置信度）

| 项 | 内容 |
|---|---|
| 理论含义 | 系统处于临界态且噪声强度适中时，弱信号被噪声放大而触发相变 |
| 可观测代理 | 临界度 ×（噪声适配度 与 前置条件 的均值） |
| 输入字段 | `spectral_width`、`dci`、`close` |
| 公式 | `criticality = 1 - percentile_rank(spectral_width, Ws)`<br>`noise_fit = exp( -(dci_vol - target)² / (2·width²) )`<br>`trigger_pre = 1 - percentile_rank(BBW, Wv)`<br>`resonance_score = criticality × 0.5 × (noise_fit + trigger_pre)` |
| 计算窗口 | 谱宽分位窗口 `168`，`dci_vol` 窗口 `24`，BBW 分位窗口 `168` |
| 输出范围 | [0, 1] |
| 缺失值处理 | 谱宽缺失 → `None` |
| 是否使用未来数据 | **否** |
| 理论预测 | 共振触发后，趋势扩张的概率与幅度显著高于非共振时点 |
| 否证条件 | 若共振分数的分位数与后续收益无单调关系，则否证 |

> **结构设计说明**：采用**乘法**而非加法，因为随机共振要求「临界态」与「噪声适中」**同时成立**，加法会让单一强条件掩盖另一条件的缺失。
>
> **与旧实现的差异**：`nemt_signals.py:431` 的 `confidence = conditions_met / 3.0`，而 L423 已硬性 AND 三条件，导致触发时**恒为 1.0**，是退化常数；`nemt_state_machine.py:286` 的 `>= 0.6` 阈值因此永真，属死代码。本实现输出连续分数。
>
> ⚠️ **代理量声明**：原文三条件为 ① 长周期链上临界（MVRV/NUPL/LTH）② 短周期噪声适中 ③ 外部触发事件。① ③ 需链上与宏观数据，本实现以「谱宽低分位」「BBW 低分位」替代。

### 2.9 market_phase（市场相位）

| 项 | 内容 |
|---|---|
| 理论含义 | 市场在「混乱 → 蓄力 → 临界 → 趋势」四相位间的状态 |
| 可观测代理 | 由 DCI / vortex_score / resonance_score 按优先级判定 |
| 输入字段 | `dci`、`vortex_score`、`resonance_score` |
| 判定规则 | `resonance_score ≥ 0.60 → C`<br>`elif vortex_score ≥ 0.60 → B`<br>`elif dci is None → UNKNOWN`<br>`elif dci < 0.55 → A`<br>`elif dci > 0.65 → D`<br>`else → A` |
| 计算窗口 | 继承上述各变量窗口 |
| 输出范围 | `A` / `B` / `C` / `D` / `UNKNOWN` |
| 缺失值处理 | **数据不足返回 `UNKNOWN`，不猜测、不默认给 A** |
| 是否使用未来数据 | **否** |
| 理论预测 | 相位 B/C 之后进入 D 的概率高于随机时点 |
| 否证条件 | 若 B/C 相位后的收益分布与随机时点无异，则相位划分无预测力 |

| 相位 | 含义 |
|---|---|
| A | 高噪声混乱期 |
| B | 涡旋蓄力期 |
| C | 临界爆发前夜 |
| D | 趋势运行期 |
| UNKNOWN | 数据不足，不参与任何统计 |

## 3. 数值方法约定

NLS 采用标准形式：

```
i ∂ψ/∂t + α ∂²ψ/∂x² + β|ψ|²ψ = η
⇒  ψ_t = i·α·ψ_xx + i·β|ψ|²ψ - i·η
```

Split-step Fourier 单步：

1. 非线性相位：`ψ *= exp(i·β·|ψ|²·dt)`
2. 线性色散（频域）：`ψ̂ *= exp(-i·α·ω²·dt)`，其中 `ω = 2π·k/N`（k > N/2 时取 k-N 表示负频率）
3. 噪声：`ψ += N(0, η·√dt)`

> 仓库内 Euler / RK4 / SSFM 三种离散化互相不可比（色散符号、边界条件、噪声尺度均不同，`nls_solver.py:158` 还有 `/dx` 而非 `/dx²` 的量纲错误）。本实现**只保留 SSFM** 并明确上述约定，FFT 隐含周期性边界。
>
> 自研 FFT 已与 `numpy.fft.fft` 逐点比对，**最大误差 0.00e+00**，可放心使用；采用纯标准库实现以保证跨机器可复现。
