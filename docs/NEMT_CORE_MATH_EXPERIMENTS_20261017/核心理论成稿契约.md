# 核心理论成稿契约

## 1. 最终文件只允许保留的数学层级

### 层级 A：严格数学事实

- 受迫随机 NLS 方程及明确的噪声协方差约定。
- 无量纲化与控制参数 Γ、Θ。
- 无噪声守恒量、对称性和解析孤子。
- 经数值收敛验证的动力学解。

### 层级 B：实验支持的结构事实

- 由实验二恢复的相区、序参量和边界不确定性。
- 临界减速、滞后或状态转移，仅在对应判据通过时保留。
- 状态数由模型证据决定，不预设必须为四。

### 层级 C：经济映射

- α、β、η 的经济名称必须逐项通过 CM3.3–CM3.6。
- 未通过的参数只保留数学名称。
- 相关映射不得写成因果机制。

## 2. 最终核心公式表

最终版本至少应包含：原始方程、无量纲方程、Γ 与 Θ、质量与哈密顿量、孤子解、四个候选序参量、参数状态空间链接、识别似然/目标函数和状态转移概率。每个公式旁必须列出：定义域、单位或无量纲性、可观测输入、估计方法、识别条件、失败状态。

## 3. 最终核心图表

只保留八类图：公式缩放图、尺度坍缩图、Γ–Θ 相图、序参量曲面、临界诊断图、状态转移矩阵、参数后验轨迹、经济变量偏效应/负对照图。预测收益曲线不属于这份核心理论文件。

## 4. 成稿结论规则

- 三项全部通过：可以形成“数学闭合 + 相变结构 + 有限经济映射”的 NEMT 核心版本。
- 实验一通过、实验二失败：保留 NLS 数学模型，删除离散相位理论，改用连续序参量。
- 实验一、二通过，实验三失败：保留数学动力学，不赋予 α、β、η 经济名称。
- 实验一失败：NEMT 不具备单一无量纲核心，应回到多参数生成模型，不制作简化核心公式版。

## 5. 与此前实验的关系

上一组三项实验提供求解器可信度和谱宽失败证据，应作为前置事实引用。此前规划的稳定边界、稳健观测量和 BTC 预测实验仍有价值，但在本三项完成前不应被描述为理论核心验证。
