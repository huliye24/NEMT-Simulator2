# NEMT 核心数学—经济学实验纲领

版本：1.0（内部专业版，运行前冻结）  
日期：2026-10-17

## 目的

本实验组服务于一份只保留 NEMT 最核心数学公式、相图和经济解释的内部理论文件。它不以预测收益或读者可读性为目标，而以理论闭合为目标：

1. 方程是否能压缩为少数无量纲控制量；
2. 所谓“相位”是否对应稳定、可重复的动力学区域；
3. 数学参数是否能由市场微观结构和宏观状态识别，而不是事后贴标签。

## 优先级

这三项实验优先于此前规划的稳健观测量筛选和 BTC 样本外预测。新的依赖链为：

`核心实验一 → 核心实验二 → 核心实验三 → 观测量筛选 → 样本外预测`

任何核心实验失败都必须导致理论公式、图表或经济标签的删减，而不是降低阈值。

## 三项实验

- `exp_core_1_dimensionless/实验设计.md`：无量纲化、对称性、守恒律与尺度坍缩。
- `exp_core_2_phase_transition/实验设计.md`：分岔、序参量、临界现象与四相位可证伪化。
- `exp_core_3_economic_identification/实验设计.md`：α、β、η 的逆问题、经济映射和跨市场识别。
- `核心理论成稿契约.md`：实验结果如何进入最终公式与图表版本。
