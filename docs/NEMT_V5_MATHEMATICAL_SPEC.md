# NEMT v5 数学设计：4小时数据与周级趋势价值

## 版本边界

NEMT v5 不独立预测方向。首仓方向仍只允许来自 NEMT 的
`critical_up` 或 `critical_down` 临界事件；v5 新增的职责，是判断这个
事件是否仍具有至少一周的剩余趋势价值。年度趋势不参与方向和仓位。

## 时间尺度

- 基础数据：4小时已完成K线。
- 候选持有周期：42、84、126、252根K线，即1、2、3、6周。
- 同类临界事件至少间隔12根K线，避免把一次趋势重复计数。
- 所有训练事件的完整持有周期必须在当前决策时间以前结束。

## 历史状态向量

每个 NEMT 临界事件使用以下因果特征：

1. 18、42、126、252根K线收益；
2. 42、126根K线方向效率；
3. 42根实现波动率；
4. 18/42根波动率比；
5. NEMT ψ、熵和临界评分。

只在方向相同的历史临界事件中寻找距离最近的48个状态。距离按各特征
的历史标准差归一化，并使用指数核赋权。

## 真实R标签

每个历史事件按照当时的14周期ATR设置2ATR保护止损，并计入双边5 bps
手续费和2 bps滑点。若先触发止损，结果记为含成本的负R；否则以候选
周期末的收盘价计算方向收益并换算为R。

## 开单目标函数

v5 不设置胜率门槛。对每个候选周期计算四分之一风险分数下的对数效用：

```text
uᵢ = log(max(0.05, 1 + 0.25 × Rᵢ))
```

再对相似历史事件计算加权均值，并扣除估计误差：

```text
LCB = E_w[u] - 0.84 × sqrt(Var_w[u] / N_eff)
```

选择 LCB 最大的持有周期。只有当最佳周期 `LCB > 0` 时，v5 才允许
v4.4 的 NEMT 首仓候选进入执行层。胜率、盈亏比和预期R只作为诊断量。

## 执行与风险

- 单账户、禁止重叠持仓；
- 杠杆上限3倍；
- 每笔初始止损风险为权益1%；
- 保护止损随时有效；
- 至少持有一周后才启用2ATR移动保护；
- 计划周期结束后，只有NEMT衰减或反向确认才退出；
- 本研究版本不创建 PAPER、TESTNET 或 LIVE 订单。

## 2025实验结论

第一版数学模型未通过：历史少数巨大盈利事件仍使低胜率多头的对数增长
下界略为正，导致8个许可全部偏向做多。2025年实际发生6次止损，说明
当前不确定性估计没有充分处理重尾分布和状态漂移。该版本保持研究状态，
不得替代 v4.4。
