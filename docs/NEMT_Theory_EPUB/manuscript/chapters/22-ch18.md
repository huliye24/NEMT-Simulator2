## 二、N01：Macro Trend Engine（宏观趋势引擎）

### 功能定义

将宏观变量数据集转化为综合趋势评分 MacroTrendScore ∈ [0, 100]。

### 输入

```text
MacroData = {
  dollar_index, fed_funds_rate, inflation_exp,
  global_liquidity, vix, btc_etf_flow,
  stablecoin_mcap_change, funding_rate,
  open_interest, long_term_holder_ratio
}
```

### 输出

```text
MacroTrendScore ∈ [0, 100]
// >70: 强顺风 | 50-70: 弱顺风 | 30-50: 中性 | <30: 逆风
```

### 关联论文

```text
| 论文 | 映射内容 | 映射强度 |
| Macro Trend Engine 的设计 | 引擎整体架构、评分公式、子项权重 | 直接映射（核心） |
| 宏观趋势调度学总论 第七节 | 宏观变量的上层环境理论 | 理论依据 |
| 宏观趋势调度学研究纲领 第二章 | 宏观经济基础五周期 | 框架依据 |
| 美元指数与比特币走势的关系研究 | DollarPressureScore 子项 | 信号来源 |
| 美联储利率周期对比特币市场的影响 | RateExpectationScore 子项 | 信号来源 |
| 全球流动性扩张与加密资产牛市的关系 | LiquidityScore 子项 | 信号来源 |
| 通胀预期如何影响比特币叙事 | NarrativeScore 子项 | 信号来源 |
| WCAE-MTS-FORM-001 第三节 | MacroTrendScore 精确公式 | 公式来源 |
```
