## 2. V2 冻结公式

对入场前全部已关闭交易的净 `R` 序列计算：

1. 保守均值 `mu_L = max(0, mean(R) - 1.645 * stdev(R) / sqrt(n))`；
2. 二阶 log-growth Kelly `f_K = mu_L / mean(R^2)`；
3. 用长度 3 的移动块 bootstrap 生成 2,000 条、每条 24 笔的路径，计算累计 `R` 的最大回撤，取第 95 百分位 `Q95`；
4. 当前权益相对峰值为 `w = 1 - D`，15% 目标回撤对应财富底线 0.85，剩余预算 `B = max(0, (w - 0.85) / w)`；
5. 最终风险比例 `f = min(2%, f_K, B / Q95)`。若 `mu_L <= 0`、`Q95` 无效或当前回撤达到 15%，风险为 0。

随机种子固定为 `20261026 + 20000 + n`。每笔平仓后才更新 `R` 历史，不允许读取未来交易。15% 来自项目既定目标回撤标准，20% 是候选淘汰硬线。
