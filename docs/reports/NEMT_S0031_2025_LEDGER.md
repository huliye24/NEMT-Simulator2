## 2. arm C 达成了它唯一的设计目标

C1 与 T3 的差异**只有**一条：第 2 批成交后把共享止损上移到扣除双边成本后的平衡价。

| 指标 | T3 | **C1** | 判定 |
| --- | ---: | ---: | --- |
| 期末权益 | 96.1087 | **96.9245** | +0.82 USDT |
| 最大回撤 | 7.534% | **7.141%** | 略好 |
| **`max_open_risk_pct`** | **1.002%** | **0.502%** | **合并未平风险减半** |
| 止损上移次数 | 0 | **12** | 规则生效 |
| 完成交易 | 18 | 20 | 提前离场腾出账户 |
| 盈利/亏损 | 3 / 15 | **7 / 13** | 把部分亏损转成小赢/持平 |
| 盈利因子 | 0.577 | 0.540 | **右尾被削弱** |
| 删除最大 1 笔后 | -6.22% | **-5.31%** | 单笔依赖更轻 |

**S-003.1 §4 要求的"合并风险始终受控"被实测验证了**（1.00% → 0.50%）。
但代价明确：胜率从 3/15 升到 7/13，盈利因子却从 0.577 降到 0.540——
平衡止损把"本会亏损"的仓位变成小赢或打平，同时**砍掉了右尾**。

而 C1 的"保护"代价不对称：**2023 一年就损失 14.33 USDT 的上行，2025 只挽回 0.82 USDT**。

## 5. 必须直说的一句话

用户关心"一年能赚多少"。这套策略族六年独立年度的**实盘尺度现实**是：

| 年 | 100 USDT 起，臂 A 期末 |
| --- | ---: |
| 2021 | 117.13 |
| 2022 | 102.57 |
| 2023 | **140.89** |
| 2024 | 110.44 |
| 2025 | **93.67** |
| 2026 至今 | 120.31 |

- 六年拼接（独立年度相乘）≈ `×2.24`，即 **+124%**，平均约 **+14%/年**，其中一年亏损。
- 每年只有 **11–24 笔**交易，收益由极少数右尾交易决定（2025 删掉最大一笔后 R0 变 -10.02%）。
- 我们已经测过的所有改动——ψ/熵门槛、20/55 日通道、周级确认、分批、平衡止损、滚动权益、
  分批记账——**没有任何一个把年收益推到 40.89% 以上**。
- S-003 §1 已写明：**100x/1 年需要 +9900%**。这份数据里**不存在**通往数量级增长的路径。

**结论：如果目标是"一年赚很多"，这个策略族不是合适载体，调参也解决不了。**
它目前的真实特征是：中低个位数到几十个百分点的年收益、非零的亏损年、极小的样本量。
