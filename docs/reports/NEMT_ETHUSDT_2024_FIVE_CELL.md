## 2. 这是本轮最重要的发现：删掉最大赢家后仍然为正

**在此之前所有窗口、所有配置，删掉最大一笔交易后都会转负或归零**（例如 BTC 2024
五个配置全部变成 −2.77% ~ −9.27%）。

ETH 2024 是**第一个**例外：

| 配置 | 删最大 1 笔后 |
| --- | ---: |
| R0 | +1.08% |
| F0 | +1.19% |
| T3 | +1.47% |
| T2 | +1.62% |
| C1 | +1.88% |

也就是说 ETH 上的正收益不是单笔撑起来的——4 笔盈利分散在不同时间，
单笔依赖明显低于 BTC 的任何窗口。这是**证据质量上的提升**，不只是数字变好。

## 6. 必须同时声明的限制

1. **单一年份、单一新资产**：ETH 2024 只有 16–17 笔交易，仍属小样本。
2. **ETH 与 BTC 高度相关**（2024 年日收益相关性通常 >0.7），所以"跨资产"不等于
   独立信息；ETH 上更好也可能是同一次市场结构在两个资产上的相似表现。
3. **2024 是上涨年**（ETH +48.72%），结论不能外推到下跌年。要检验 ETH 的下跌年
   需要另立窗口（2022 或 2025）。
4. **参数仍来自 BTC**：本轮没有按 ETH 调整任何参数，也没有为了 ETH 结果回头修改
   BTC 参数（那会同时污染两个市场）。
5. 未计资金费率、强平阶梯、延迟、盘口深度。
6. **不授权 PAPER / TESTNET / LIVE**。
