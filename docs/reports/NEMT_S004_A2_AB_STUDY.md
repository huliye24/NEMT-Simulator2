# S-004.A.2 — 事件级 A/B：过滤器拒绝了 100% 的最大赢家

- **方法**：把**门控**与**执行**完全解耦。枚举全部 Donchian+NEMT 候选（允许假设性重叠），
  对每个候选独立模拟到它自己的退出，再与该决策时点的 S-004.A 判定配对。
- **规模**：10 币 × 4 年，**2,356 个候选**，基准合计 **+1,104.2R**
- **证据等级**：`EXPLORATORY`（2022–2025 已被反复使用）
- **订单权限**：无。未创建 PAPER / TESTNET / LIVE 订单

## 0. 为什么必须解耦

上一轮的比较是错的：R0 的 699 笔真实交易是在**持仓互斥**约束下产生的，
一个信号被拒绝后会腾出仓位给后面的信号，所以"过滤后的组合"和"原组合"
不是同一批交易的子集，不能 1:1 对比。

本轮的 2,356 个候选**允许重叠**，因此是纯粹的**信号质量测量**——
正是回答"过滤器值不值得保留"所需的样本。

过滤器确实删掉了大量亏损交易——A5 删掉了 92.5% 的候选——**但它同时删掉了

### Q3：保留的交易，平均净 R 是否提高？

| 配置 | 全部均 R | **许可均 R** | 拒绝均 R | 判定 |
| --- | ---: | ---: | ---: | --- |
| A1 | +0.469 | **+0.272** | **+0.582** | **反向选择（更差）** |
| A2 | +0.469 | +0.477 | +0.466 | 几乎不变 |
| A3 | +0.469 | +0.415 | +0.478 | 略差 |
| A4 | +0.469 | +0.435 | +0.483 | 略差 |
| A5 | +0.469 | **+0.650** | +0.454 | **提高 39%** |

**只有最严的 A5 提高了均 R。而最松的 A1 反而系统性挑出更差的交易**
（+0.272 vs 被拒的 +0.582）——**在最松端，这个过滤器是负向选择器。**

### Q4：减少交易频率后，总收益是否仍能超过原策略？

固定分数权益（按决策时点排序，每笔 1% 风险）：

| 配置 | 交易数 | **4 年终值** | 相对全做 |
| --- | ---: | ---: | ---: |
| **全做（2,356 笔）** | 2,356 | **×3,386.9** | 1× |
| A4 许可（691 笔） | 691 | ×13.88 | **1/244** |
| A2 许可（583 笔） | 583 | ×11.59 | 1/292 |
| A1 许可（863 笔） | 863 | ×6.997 | **1/484** |

**否。过滤后的总收益是全做的 1/244 到 1/484。**

⚠️ 注意：全做的 ×3,386 不可执行（2,356 笔重叠持仓会远超杠杆上限）。
这里比较的是**同一口径下的信号价值**，不是可实现收益。

### Q5：最大回撤是否真正改善？

| 配置 | 最大回撤 |
| --- | ---: |
| 全做 | 95.2% |
| A1 许可 | 87.3% |
| A4 许可 | 77.9% |
| A2 许可 | 71.2% |

**从 95.2% 降到 71.2%–87.3%——仍然是灾难级。** 在这个候选池里，
无论做不做过滤，等权固定分数的回撤都在 70% 以上。

## 3. 最重要的机制：均 R 上升 ≠ 总 R 上升

A5 是最好的反例：

| 配置 | 许可率 | **均 R（最高）** | **保留的 R** |
| --- | ---: | ---: | ---: |
| **A5** | 7.5% | **+0.650** | **+115.0R（最低）** |
| A4 | 29.3% | +0.435 | **+300.4R（最高）** |

A5 的均 R 比 A4 高 49%，但它保留的总 R 只有 A4 的 38%。
**因为它把右尾整个削掉了：均 R 是靠"删除极端值"提高的。**

这就是"用均 R 评价过滤器"的陷阱，也正是你指出的那个危险：
**过滤器可以一边改善统计量，一边毁掉收益来源。**

## 4. 判定

按 S-004 §52 规定的报告项，逐条：

| S-004 要求 | 实测 |
| --- | --- |
| 原始候选数 | 2,356 |
| 许可率 | 7.5%–36.6% |
| 净 R 分布 | 许可均 R +0.272 ~ +0.650（全做 +0.469） |
| **失去的前 1% 大赢家** | **24 / 24，全部失去** |
| 失去的前 5% 大赢家 | 54%–91% 被拒 |
| 成本后收益 | 全做的 1/244 ~ 1/484 |
| 最大回撤 | 95.2% → 71.2%–87.3%（无实质改善） |

**结论：S-004.A 过滤器必须在进入 B 臂（盈利加仓）之前被否决。**
它没有通过"值得保留"的第一道门槛——不是因为它减少了交易，而是因为
**它保留了更差的交易、删除了最好的交易**。

## 5. 为什么结构性必然（补充上一轮的结论）

上一轮已证明：多周期一致性（13/26/52 周同向）要到趋势走满一年才成立，
而右尾在那之前已经发生。本轮给了量化证据：

- 24 笔最大赢家的盈利规模从 +20R 到 +100R 级；
- 它们全部发生在 52 周窗口尚未同向的时期；
- 因此**任何要求 52 周一致性的过滤器，都必然拒绝 100% 的这一类交易**。

**这不是阈值问题，是定义问题。** 只要入场条件里含"52 周同向"，
0/24 就是数学上的必然结果，而不是调参调出来的。

## 6. 建议

1. **不要实施 A 臂，也不要进入 B 臂。** A 是 B 的前提，前提已被证伪。
2. 若仍想用多周期一致性，**只能用于仓位大小**（趋势确认后加仓），
   不能用于入场许可——这样不会删除候选，只改变规模。
3. **C 臂（条件性对冲）可独立做**：以 `HOLD`/`REDUCE`/`EXIT` 为对照，
   不依赖 A 通过，且空头腿期望≈0，对冲成本接近零。
4. 建议 S-004 修订 A 臂假设：把"稀疏筛选"改为"**尾部保护**"——
   即不做入场过滤，而是检测"是否处于会破坏右尾的状态"。
