# 从概率论看：这套策略的数学上限是每年 14.6%

- **数据**：699 笔基线交易（R0，1% 风险，10 币 × 4 年）
- **计算**：`E[log(1+f·R)]` 精确凯利曲线（非近似）+ 20,000 条蒙特卡洛路径
- **证据等级**：`EXPLORATORY`

## 0. 先回答"这是我们的交易策略吗"

**不是。** 我们回测的东西是：

```text
120 根 Donchian 突破 + 60 根反向通道退出 + 2N 止损 + 1% 风险 + 3x 杠杆
```

NEMT 在其中的作用是一个**二元许可**（`critical_up/down` 方向一致才放行）。而实测：

| 观测 | 数值 |
| --- | --- |
| BTC 2022 Donchian 突破候选 | 63 |
| 其中 NEMT 方向一致 | **62** |
| **NEMT 拒绝比例** | **1/63 ≈ 1.6%** |

**98.4% 的交易由海龟法则（1970 年代的突破规则）产生，NEMT 只做了一次几乎不生效的确认。**

理论仓库自己也写明了这一点：

- `theory/CORE_THEORY.md` §52：「NEMT 信号与趋势突破同时出现，**并不自动证明 NEMT 拥有独立预测力**」
- §59：「`S` 是对最近 120 个收盘价的价格直方图熵……**只要价格的多重集合不变，重排观察顺序不会改变 `S`**」
  —— 即 S 是**排列不变量**，无法描述时间顺序或熵产生
- §33：「临界状态是**候选信号而不是订单**」

而专门为检验 NEMT 增量信息而设计的 v5.2.6 实验（`Δ_R`，同一批候选有无 NEMT 许可的差异）：

| 年份 | Δ_R | 样本 |
| --- | ---: | ---: |
| 2023 | **−8.27** | 16 笔 |
| 2024 | +0.28 | 10 笔 |
| 2025 | +0.35 | 19 笔 |
| 2026 YTD | −0.43 | 16 笔 |

**在唯一有像样样本的年份（2023，16 笔），NEMT 许可的边际是负的 −8.27R。**

结论：**理论是一套状态分类法；我们实际交易的是一个经典突破策略，附带一个从未被证明有效的标签。**

## 1. 第一层数学：可选停时定理

对**无漂移随机游走**（鞅），任意停时规则都满足 `E[退出价] = 入场价`。
这就是可选停时定理（optional stopping theorem）。

推论：**任何止损/止盈的摆放，都不能创造正期望——只能改变分布形状。**

这精确解释了上一轮的实测结果：止损从 2N 放宽到 3N/4N/5N，
均值收益单调下降（+9.47% → +5.66%）。**因为放宽止损是保鞅变换（martingale-preserving）。**

由此可知：+0.554R 的正期望**全部**来自价格序列的非鞅部分——即漂移与自相关（动量）。
我们多空几乎对半（16,387 / 16,920），漂移互相抵消，所以**边际来自弱动量**。

## 2. 第二层数学：期望的三个要素

```text
E[R] = p·W − (1−p)·L
```

| 量 | 实测值 |
| --- | ---: |
| 胜率 `p` | **20.89%** |
| 平均盈利 `W` | **+6.42 R** |
| 平均亏损 `L` | **−0.995 R** |
| `p·W` | +1.341 |
| `(1−p)·|L|` | 0.787 |
| **`E[R]`** | **+0.554 R** |
| 该 W 下的盈亏平衡胜率 | **13.42%** |

**`L` 被止损锁死在 ≈1R，所以边际只能靠提高 `p` 或 `W`。**
而 `p` 由止损位置决定（前面已证明改不了），`W` 由退出规则决定（通道退出已偏早，
但放宽会缩小仓位）。

## 3. 第三层数学：凯利上限 = 每年 +14.6%

用精确式 `g(f) = E[log(1 + f·R)]` 在 699 个 R 上求解（不是 `μ/σ²` 近似，
因为分布尾部极重，近似会严重失真）：

| 单笔风险 `f` | 每笔对数增长 | **年化（18 笔/年）** |
| ---: | ---: | ---: |
| 1% | 0.409% | +7.65% |
| 2% | 0.633% | +12.07% |
| 3% | 0.740% | +14.24% |
| **3.5%（最优）** | **0.759%** | **+14.64%** |
| 5% | 0.708% | +13.59% |
| 7.5% | 0.341% | +6.32% |
| **10%** | **−0.298%** | **−5.23%** |

**这就是"为什么表现这么差"的最终答案：**

> 这套边际（0.55R/笔 × 18 笔/年）在**数学上**允许的最大复利增长是 **+14.6%/年**。
> 风险超过 3.5% 之后，**增长开始下降**；到 10% 时**理论年化是 −5.2%**。

所以此前看到的 BTC 2023 在 5% 风险下 +181.9%、10× 杠杆下 +531%——
**都是 p95 以外的幸存路径，不是期望值。**

## 4. 第四层数学：方差拖累吃掉 61%

在最优 `f = 3.5%` 处：

| 量 | 值 |
| --- | ---: |
| 算术期望 `f·E[R]` | **1.94%** / 笔 |
| 实际对数增长 `E[log(1+fR)]` | **0.76%** / 笔 |
| **方差拖累** | **1.18% / 笔（占算术期望的 61%）** |

原因在分布形状：

| 矩 | 值 |
| --- | ---: |
| 均值 | +0.5536 R |
| 标准差 | 6.2599 R |
| **偏度** | **10.29** |
| **超额峰度** | **146.54** |
| 最小 / 最大 | −1.082 / **+109.53** |
| 中位数 | −1.024 |

**超额峰度 146** 意味着 4 阶矩被极少数样本主导。在这种分布下，
"平均每笔赚 0.55R"这个数字本身极不稳定。

## 5. 第五层数学：统计显著性只是勉强

```text
标准误 SE = σ / √n = 6.2599 / √699 = 0.237
95% 置信区间 = 0.554 ± 0.465  →  [0.089, 1.019]
t 统计量 ≈ 2.33
```

**边际在统计上只是勉强显著（约 2.3σ），且下界只有 0.089R。**

更糟的是集中度：最大单笔 +109.53R 对均值的贡献是

```text
109.53 / 699 = 0.157 R  →  占整个边际 0.554R 的 28%
```

**699 笔交易的全部边际，有 28% 来自其中 1 笔。**

## 6. 蒙特卡洛：风险的真相

20,000 条路径 × 72 笔（4 年）：

| 风险 | 4 年中位倍数 | 5% 分位 | 95% 分位 | 中位最大回撤 | P(回撤>50%) | P(账户腰斩) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1% | 1.250 | 0.765 | 2.957 | 17.6% | 0.0% | 0.0% |
| 2% | 1.419 | 0.572 | 6.137 | 32.5% | 7.8% | 2.3% |
| **3%** | **1.551** | 0.421 | 10.947 | 44.8% | 36.2% | 8.5% |
| 5% | 1.444 | 0.206 | 22.344 | 64.6% | 83.4% | 20.8% |
| 7.5% | 1.089 | 0.076 | 37.918 | 80.2% | 98.2% | 33.3% |
| **10%** | **0.692** | **0.026** | 49.376 | 89.6% | 99.9% | **44.4%** |

**在 10% 风险下：4 年中位数只剩 69%（净亏 31%），44.4% 的概率账户腰斩，
5% 分位只剩 2.6%。** 而 95% 分位是 49 倍——**正是那些 49 倍让我们误以为 10% 风险很好。**

## 7. 结论

**为什么表现差？不是因为执行、参数或运气，而是因为边际本身太小，
而小边际的凯利上限就是每年十几个百分点。**

| 问题 | 答案 |
| --- | --- |
| 期望是正的吗 | 是，+0.554R/笔，但 t≈2.3，且 28% 来自 1 笔 |
| 为什么调参数没用 | 可选停时定理：调止损是保鞅变换，不产生期望 |
| 为什么放大风险没用 | 凯利上限 3.5%；超过后增长下降，10% 时理论为负 |
| 为什么单年能有 +182% | 那是 p95 幸存路径，不是期望 |
| 这套策略是 NEMT 吗 | 不是。98.4% 的交易由海龟突破产生，NEMT 的增量信息为负 |

**要真正提高收益，只有两条数学上有效的路：**

1. **提高 `p` 或 `W`**（真正的预测力）——NEMT 至今没有提供，v5.2.6 的 Δ_R 是 −8.27。
2. **提高 `N`（年交易次数）**——现金占用只有 10%–25%，多标的并行是唯一
   在不放大单笔风险的前提下提高 `N` 的办法。但**相关性会稀释**：
   10 个币相关性 0.6–0.9，有效独立标的 probably 只有 2–3 个，
   所以 `N` 能提高约 2–3 倍，而不是 10 倍。

按乐观估计 3 倍：`E[R]×N` 从 ~10R/年 提到 ~30R/年，凯利上限从 ~15% 提到 ~35–40%/年。
**这仍然不是 100%。要 100%，边际必须提高一个数量级——而那需要真正的新预测力，
不是重新排列已有指标。**

## 8. 限制

1. 699 笔为唯一信号集；不同风险档共享同一批交易。
2. 凯利计算假设单笔独立同分布（iid）；真实交易存在波动率聚集与相关性，
   实际最优 `f` 应更低，破产概率更高。
3. 蒙特卡洛用 iid 自助重抽样，**低估**真实连亏风险。
4. 未计资金费率与滑点对止损触发的影响。
