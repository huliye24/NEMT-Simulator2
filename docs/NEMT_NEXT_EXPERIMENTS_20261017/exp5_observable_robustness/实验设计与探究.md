# 实验五：稳健 NEMT 观测量筛选

> 状态：运行前冻结。目标不是把谱宽“救活”，而是在同等条件下筛选可复现的观测量。

## 1. 要回答的问题

上一组实验显示谱宽的窗口级排序对估计器和滚动窗口不稳健。本实验比较五类候选量，检验哪些量同时满足定义稳健性、重复测量可靠性和对已知状态变化的响应。

## 2. 数据生成

生成四类受控过程，每类 30 个 seed、每条 8192 点：

1. GARCH regime switch：已知波动率切换。
2. ARFIMA/GARCH：加入长记忆。
3. Jump-diffusion：已知跳跃时刻与强度。
4. Chirp + colored noise：已知频率展宽与信噪比。

每条序列用冻结的 `logprice_z` ψ 构造和实验四批准的 SSFM 配置。所有候选量同时在原始 ψ 与演化后 ψ 上计算。

## 3. 候选观测量

- 二阶矩谱宽 `W2`（上一组定义）。
- 频谱熵 `Hspec`，归一化到 `[0,1]`。
- 谱质心 `Cspec`。
- 高频尾部质量 `Tail20`：最高 20% 正频率功率占比。
- 空间逆参与率 `IPR`。

估计器为 periodogram、Hann、Welch、sine multitaper；窗口为 64、128、256；边界为周期、反射、Hann 锥化。参考设置固定为 `periodogram + N=128 + periodic`。

## 4. 主判据

对每个候选量计算：

- 定义稳健性：所有替代设置与参考设置的配对 Spearman 中位数。
- 重测可靠性：同一潜在过程、相邻非重叠窗口的 ICC。
- 状态响应：已知 regime/chirp 强度的有序效应；用 seed 分层的 Spearman 与 Cliff's delta。
- NLS 增益：演化后指标相对原始指标的交叉验证识别 AUC/回归 `R²` 改善。

| 编号 | 判据 | 通过标准 |
|---|---|---|
| C5.1 | 定义稳健性 | 跨过程的最差中位 Spearman `≥0.75` |
| C5.2 | 重测可靠性 | 跨过程 ICC 中位数 `≥0.70` |
| C5.3 | 已知状态响应 | 4 类过程中至少 3 类方向正确，且 `|ρ|≥0.30` 或 `|Cliff δ|≥0.33` |
| C5.4 | 跨 seed 泛化 | leave-seed-out 95% CI 下界仍满足 C5.3 的方向要求 |
| C5.5 | NLS 增益 | 演化后相对原始值的改进 CI 下界 `>0`；否则结论为“无 NLS 增益” |

进入实验六的资格：至少一个指标同时通过 C5.1–C5.4。若多个通过，按最差稳健性、ICC、状态响应的字典序选主指标；不得用实验六测试段挑选。

## 5. 探索内容

- 组合指标是否比单指标稳定；只可用训练 seed 拟合权重。
- 失败主要来自窗口长度、边界还是谱估计器。
- NLS 演化是否只是平滑，而非增加状态信息。
- `W2` 若失败，明确判断其失败属于定义不稳健还是状态响应不足。

## 6. 预估结果

最可能结果是 `W2` 再次因排序敏感而失败，`Hspec` 或 `Tail20` 在估计器变化下更稳健，`IPR` 对局部化过程最敏感。NLS 演化后的增益可能接近零；这仍是重要结论，意味着应把价值归因于观测量本身，而非 NLS 传播。
