# 实验四：固定步数稳定性边界与长时误差

> 状态：运行前冻结。不得在看到结果后修改网格或阈值。

## 1. 要回答的问题

上一组固定总时间 `T=0.2` 的扫描在大 `dt` 时只运行一至两步，无法识别发散边界。本实验改用固定步数，回答：三种求解器的经验稳定性边界如何随 N 缩放；即使不发散，长期质量、能量和相位误差是否已不可接受。

## 2. 假设

- H4.1：Euler 的临界步长随网格细化显著下降，`dt_c ∝ dx^p`，拟合指数 `p` 接近 2。
- H4.2：SSFM 在全部扫描网格上保持有限且相对质量误差 `<1e-10`。
- H4.3：在共同稳定区，RK4 与 SSFM 的孤子相位误差明显低于 Euler；SSFM 的模长误差最小。
- H4.4：只用“未发散”会高估可用步长；精度边界 `dt_a` 严格小于或等于发散边界 `dt_c`。

## 3. 初值与参数

使用两个初值：解析孤子 P1 和上一组固定 seed 的合成市场剖面 P2。

- `N ∈ {32,64,128,256,512}`，物理区间长度固定为 128，因此 `dx=128/N`。
- `dt ∈ logspace(-5,0,51)`。
- 固定 `steps=200`；补充长时段 `steps∈{200,1000,5000}`，只在每个 N 的共同安全步长运行。
- `alpha=0.1, beta=1, eta=0`。
- solver：Euler、RK4、SSFM；不得启用振幅钳制。

## 4. 判定定义

发散：出现非有限值，或 `max(abs(psi)) > 10*max(abs(psi0))`，或相对质量误差 `>1`。`dt_c` 定义为第一个发散 dt 的前一个网格点；若全不发散则右删失，不填造数值。

精度失效：满足任一条件即失效：相对质量误差 `>1e-3`、相对能量误差 `>1e-2`、P1 模长误差 `>1%`、P1 去除全局相位后的 L2 误差 `>2%`。`dt_a` 为最后一个仍满足全部精度条件的步长。

## 5. 主判据

| 编号 | 判据 | 通过标准 |
|---|---|---|
| C4.1 | 边界可测 | Euler 至少 4/5 个 N 获得有限 `dt_c`，且无参数点少于 20 步 |
| C4.2 | 缩放关系 | `log(dt_c)` 对 `log(dx)` 回归 `R²≥0.8`；报告 p 与 95% CI，不强制 p=2 |
| C4.3 | SSFM 质量 | 全部有限扫描点的最大相对质量误差 `<1e-10` |
| C4.4 | 精度先于发散 | Euler 至少 4/5 个 N 满足 `dt_a < dt_c` |
| C4.5 | 长时可信 | SSFM 在 5000 步时 P1 模长误差 `<2%` 且质量误差 `<1e-10` |

## 6. 探索内容

- RK4 的 `dt_c` 与 `dt_a` 缩放是否与 Euler 同阶但常数更优。
- 边界是否由线性色散项还是非线性峰值主导；通过 P1/P2 差异判断。
- 全局相位漂移与模长误差是否分离。
- 以二分法在粗网格临界点附近加密 8 次，仅作为探索性估计，不替代主网格 verdict。

## 7. 预估结果

最可能结果是 Euler 的 `dt_c` 随 `dx²` 下降，且 `dt_a` 明显早于肉眼可见发散；RK4 的安全区更宽；SSFM 质量守恒仍接近机器精度，但长时能量和相位存在分裂误差。若 SSFM 长时模长失败，实验五、六必须 BLOCKED，先修正边界或步长。
