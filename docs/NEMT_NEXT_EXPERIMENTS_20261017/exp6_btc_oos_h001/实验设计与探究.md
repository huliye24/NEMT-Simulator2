# 实验六：BTC 样本外 H001 检验

> 状态：运行前冻结。真实测试段在指标与模型冻结前不得查看结果。

## 1. 要回答的问题

冻结后的 NEMT 观测量能否在真实 BTC 数据上，对未来已实现波动率或极端波动事件提供超过朴素基线的样本外信息？这是第一项真实市场检验，但仍不是对全部 NEMT 理论的验证。

## 2. 数据规范

- 标的：BTCUSDT spot，1h K 线，来源固定为 Binance 公共历史数据。
- 区间：2019-01-01 00:00 UTC 至 2026-09-30 23:00 UTC；若数据源无法完整覆盖则记 INCONCLUSIVE，不后移测试边界。
- 字段：open time、open、high、low、close、volume、quote volume、trade count。
- 去重后按 open time 排序；保留原始下载文件及 SHA-256。
- 缺失连续 1–3 根时不插值价格，直接让跨缺口窗口失效；连续超过 3 根记数据事件。

固定切分：

- 训练：2019-01-01 至 2022-12-31。
- 验证：2023-01-01 至 2024-06-30。
- 测试：2024-07-01 至 2026-09-30。

## 3. 目标与特征

主目标：未来 24 小时已实现波动率 `log RV_future_24`。次目标：未来 24 小时内是否出现训练段定义的 95% 极端波动事件。

主 NEMT 特征只能读取实验五 `exp5_selected_metric.json`。同时保留上一组 `W2` 作为诊断性对照，但它不拥有主假设地位。

基线特征：当前 24h、72h、168h RV，绝对收益 EMA，成交量 z-score，小时/星期周期项。禁止引入外部情绪、链上或宏观变量。

## 4. 模型与验证

模型 A：历史均值；模型 B：HAR-RV 基线；模型 C：HAR-RV + 冻结 NEMT 指标。所有超参数只在训练/验证段选择一次，测试段只评估一次。

评价：

- 连续目标：QLIKE、MAE、样本外 `R²_oos`。
- 极端事件：PR-AUC、ROC-AUC、Brier score。
- 模型 B 与 C 的损失差用 Diebold-Mariano 检验，HAC lag=24；同时做按周 block bootstrap 2000 次。
- 稳健性切片：高/低波动、上涨/下跌、2024 减半前后；均为次要分析。

## 5. 主判据

| 编号 | 判据 | 通过标准 |
|---|---|---|
| C6.1 | 数据完整性 | 测试段有效窗口 ≥95%，无未来泄漏断言全部通过 |
| C6.2 | 波动率增量 | 模型 C 相对 B 的测试 QLIKE 改善 `≥1%`，DM `p<0.05`，block-bootstrap 95% CI 下界 `>0` |
| C6.3 | 样本外解释力 | `R²_oos(C) > R²_oos(B)` 且差值 `≥0.005` |
| C6.4 | 极端事件增量 | PR-AUC 相对提升 `≥3%` 且 Brier score 不恶化 |
| C6.5 | 方向稳定 | 至少 3/4 半年度测试块中 NEMT 系数同号，且主效果不是由单一块贡献 |

主结论以 C6.2 为核心：C6.2 PASS 才能声称“存在样本外增量信息”。C6.3/C6.4 用于效应大小与用途解释，不能替代 C6.2。

## 6. 安慰剂与负对照

- 将 NEMT 指标循环平移随机 7–30 天，重复 200 次。
- 在每月内部随机打乱指标顺序，保留边际分布。
- 用未经 NLS 演化的同名原始指标替换。

真实增益应显著高于安慰剂分布的 95% 分位；否则即使 C6.2 偶然通过，也标为 FRAGILE，不写成确认性结论。

## 7. 探索内容

- 指标在不同市场状态下是否仅提供条件性价值。
- NLS 演化相对原始指标是否有独立增益。
- 预测价值是否集中在极端事件而非平均波动率。
- 交易成本或可执行性不在本实验主范围；不得把统计预测直接写成可盈利策略。

## 8. 预估结果

保守预估是：冻结指标相对 HAR-RV 的平均改善较小，可能在 0–2% QLIKE 区间；更可能在高波动或极端事件中出现条件性增益。若主判据失败，结论应是“当前 NEMT 观测量未显示稳定样本外增量信息”，而不是继续搜索窗口直到显著。
