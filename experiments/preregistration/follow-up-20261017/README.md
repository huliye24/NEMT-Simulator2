# NEMT 下一组三项实验任务包

版本：1.0（运行前冻结）  
日期：2026-10-17

本任务包承接上一组三项实验的有效结果，不重复已经回答的问题。目标是依次解决：稳定性边界没有被原协议识别、谱宽不是稳健观测量、真实市场上尚未检验 H001。

## 实验链

| 编号 | 实验 | 主要问题 | 前置门 |
|---|---|---|---|
| 实验四 | 固定步数稳定性边界与长时误差 | Euler、RK4、SSFM 的 `dt_c(N)` 和长时相位误差是什么？ | 上一组实验一 C1/C3/C5 PASS |
| 实验五 | 稳健观测量筛选 | 谱宽、谱熵、谱质心、尾部质量、IPR 中哪些能跨估计器与窗口保持排序？ | 实验四确认 SSFM 配置安全 |
| 实验六 | BTC 样本外 H001 检验 | 冻结后的 NEMT 指标是否超越朴素波动率基线？ | 实验五至少一个观测量通过稳健性门 |

依赖关系：`实验四 → 实验五 → 实验六`。任一前置门失败时，后续不得偷偷改用另一套定义继续跑；必须记录为 BLOCKED 或按文档规定的降级路径执行。

- `exp4_fixed_step_stability/实验设计与探究.md`

## 纪律

1. 本目录上传服务器后即视为冻结版本；代码 AI 不得改动判据、阈值和数据切分。
2. 探索性图表可以增加，但不得替代预注册主判据。
3. PASS、FAIL、INCONCLUSIVE、BLOCKED 均为合法结果。
4. 最终结论只能从机器输出的 verdict CSV 和冻结协议生成。
