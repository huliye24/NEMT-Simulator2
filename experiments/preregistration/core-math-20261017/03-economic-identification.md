# 核心实验三：参数逆问题与经济结构识别

> 目标：决定 α、β、η 是否有资格分别被称为流动性、非线性拥挤和外部扰动。

## 1. 识别对象

建立滚动状态空间模型：

\[
i\partial_t\psi= -\alpha_t\partial_{xx}\psi-\beta_t|\psi|^2\psi+\eta_t,
\]

并将正参数写成对数链接：

\[
\log\alpha_t=c_\alpha+w_\alpha^T z_t^{(L)},\qquad
\log\beta_t=c_\beta+w_\beta^T z_t^{(B)},
\]

\[
\log\sigma_{\eta,t}=c_\eta+w_\eta^T z_t^{(S)}.
\]

`z(L)` 为流动性变量，`z(B)` 为杠杆/拥挤变量，`z(S)` 为外部冲击与残差变量。参数经济标签只有在结构检验通过后才能保留。

## 2. 数据层

主市场为 BTCUSDT 1h；跨市场验证至少包含 ETHUSDT 1h。建议区间 2020-01-01 至最近完整季度。所有字段按 UTC 对齐。

- 流动性：bid-ask spread、盘口深度、Amihud illiquidity、成交额、price impact。
- 非线性拥挤：OI、funding、liquidation volume、basis、long-short imbalance。
- 外部扰动：大额跳跃、公告/宏观事件哑变量、无法由状态方程解释的创新方差。
- ψ 构造必须在实验开始前冻结；至少保留一个替代构造作稳健性检验。

数据不足时允许先做 Binance 可获得字段的降级版，但必须把经济命题降级，不能用成交量代理全部流动性。

## 3. 识别步骤

### Part A：合成可恢复性

生成已知时变 `α_t,β_t,σ_η,t` 的轨迹，包括独立变化、相关变化、结构突变和弱识别四种情形。比较 EKF/UKF、粒子滤波和局部窗口最小距离估计。只有合成参数恢复通过的方法才能进入真实数据。

### Part B：真实数据滚动估计

训练、验证、测试严格按时间切分。目标函数同时使用一步状态误差、守恒残差、序参量误差和正则项；超参数只在验证段确定。输出参数后验/置信区间，不只输出点估计。

### Part C：经济符号与增量解释

检验：更深盘口、更低冲击成本是否对应更高或更稳定的 α；更高 OI/funding/liquidation pressure 是否对应 β 上升；公告和跳跃是否对应 `σ_η` 上升。符号方向先由理论约定冻结，并报告标准化系数。

### Part D：排他性与负对照

- 交换流动性与杠杆变量组，检验映射是否仍同样好；
- 时间打乱与 7–30 天循环平移；
- 与无经济标签的自由参数模型比较；
- 与 VAR/HAR/GARCH 基线比较状态重建和样本外似然；
- BTC 拟合后在 ETH 上检验符号和尺度关系。

## 4. 冻结判据

| 编号 | 判据 | 通过标准 |
|---|---|---|
| CM3.1 | 合成恢复 | 三参数轨迹的中位相关均 `≥0.80`，标准化 RMSE 均 `≤0.30`，95% 区间覆盖率 85–98% |
| CM3.2 | 局部可识别 | Fisher/Hessian 条件数在至少 80% 窗口 `<1e4`，且 profile likelihood 有有限区间 |
| CM3.3 | α 经济映射 | 流动性变量组对 α 的样本外增量解释 `ΔR²≥0.05`，组置换 p `<0.05`，主要符号跨 BTC/ETH 一致 |
| CM3.4 | β 经济映射 | 杠杆变量组对 β 满足同等标准 |
| CM3.5 | η 经济映射 | 冲击窗口的 `σ_η` 相对匹配对照效应量 `|δ|≥0.33`，且事件前无显著预趋势 |
| CM3.6 | 排他性 | 正确变量分组的样本外似然优于交换分组，DM/置换 p `<0.05` |
| CM3.7 | 跨市场 | BTC 冻结映射在 ETH 上保持主要符号，且性能保留至少 50% |

## 5. 解释规则

- CM3.3 失败：α 只能称为“色散系数”，删除“市场流动性”标签。
- CM3.4 失败：β 只能称为“非线性系数”，删除“情绪/杠杆/羊群效应”标签。
- CM3.5 失败：η 只能称为“模型残差/随机强迫”，删除“外部冲击”标签。
- CM3.6 失败：即使相关显著，也属于非排他性关联，不能写成结构映射。
- 任何映射均不使用“因果”措辞，除非另有外生工具变量或自然实验。

## 6. 预估

最可能 α 与市场深度/冲击成本存在中等关联，β 与杠杆拥挤存在状态依赖而非全样本稳定关系，η 能识别跳跃但难区分外部事件与内生清算。合成恢复可能揭示 α、β 在部分窗口仍弱识别。届时最终理论应使用参数后验和置信区间，而非确定性单值。
